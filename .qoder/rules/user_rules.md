# 中文使用规范与提示词优化规范
1. 回答完整性
1.1 所有回复必须使用中文进行详细说明。
1.2 禁止简短、片段式回答，必须完整阐述思路、步骤或背景信息。
1.3 回答中可以使用示例、层级、表格等方式增强可读性，但仍必须保持中文表达。

2. 提示词优化
2.1 在进行提示词优化或编写提示语时，必须使用中文表述。
2.2 禁止在提示词中夹杂英文单词、缩写或语法结构。
2.3 提示词优化应保证逻辑清晰、易读易懂，适合中文语境下使用。
2.4 必须提供优化前后的对比示例，以验证优化效果，所有示例均使用中文。

# 终端操作规范
1. 执行环境：所有终端操作必须在 PowerShell 环境 中进行。
2. 语法要求：所有命令必须使用 PowerShell 兼容语法，禁止使用 CMD、批处理（.bat）或其他非 PowerShell 语法。
3. 异常处理：任何使用 CMD 语法的操作都视为违规，必须立即修正为 PowerShell 兼容语法。
4. 文档要求：所有操作示例、脚本及文档必须明确标注为 PowerShell 语法，禁止包含 CMD 风格示例。
