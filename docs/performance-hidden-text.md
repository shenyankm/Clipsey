# 隐藏祖先的文本定位修复与性能验收

2026-10-12；基线 `0fa7b5d`。延续[文本边界映射验收](./performance-text-range-mapping.md)，以真实 10,000 条摘录库为扩展验收规模，兼顾 100 段页面。DOM 扫描基准的段落数和数据库记录数分别记录，不将两者混为一谈。

## 问题与改动

Chrome 中，`<div style="display:none"><span>target</span></div><p>target</p>` 的 `span` 计算样式仍是 `display:inline`。原实现只检查文字直接父元素，全文回退会优先选择没有可见矩形的隐藏文字；元数据也将它计入偏移和上下文。

现在文本搜索复用 `createTextNodeWalker`，检查祖先的 `display:none`，并在一次同步遍历内缓存祖先显示状态和父元素可见性。隐藏祖先已确定时，不再读取各个后代的样式。遍历结束即丢弃缓存；下一次定位重新检查样式。仍采用文本 TreeWalker，仍访问隐藏文本节点，不声称已经剪除整棵隐藏子树。

搜索调用保留空白节点，保证跨内联元素的空格不丢失；偏移、上下文调用保留原来的空白节点处理方式。自定义元素根之外的隐藏祖先和 Text 根也接受相同检查。`visibility:hidden` 可以由子元素覆盖，`display:contents` 下的可见文字仍可定位。样式读取失败时保留原有放行与后续重试行为。

没有修改数据库、导入导出、存储、定位策略顺序、绘制引擎或默认 8ms 逐项让出主线程。旧偏移指向不同文字时，仍尝试选择器、上下文及全文回退；新增回归和原生验收覆盖这一场景。旧偏移恰好指向另一个相同文字的歧义不在本次解决范围内。

## Chrome 对照

Headless Chrome 155.0.0.0、macOS、真实 DOM、独立临时配置。Vite 加载生产源代码，仅替代设置消息传输；每项预热一次、七次取中位数。串行测量，第二轮反转规模、页面结构与 20 条绘制顺序。顺序为基线一、初始候选两轮、反向基线二、提前返回候选两轮、最终源码两轮。中间候选与最终源码的样本均保存，正式对照使用基线和最终源码两轮。

普通页面分别含 100/10,000 段，每段三个文本节点，分散结构另增加两个文本节点。计时内核对匹配文字、起始节点、批次绘制数及完整原文。隐藏场景另含 100/10,000 段嵌套隐藏内容和一个可见目标；查询目标在两种实现中相同且断言一致，另记录偏移是否为独立已知值 7。

下表为 10,000 段场景的中位数，单位 ms：

| 场景 | 第一轮：基线 → 最终 | 第二轮：基线 → 最终 |
| --- | --- | --- |
| 嵌套隐藏内容之后，单次可见目标查询 | 26.3 → 9.7 | 25.9 → 10.2 |
| 嵌套隐藏内容，无匹配查询 | 21.5 → 9.7 | 21.3 → 9.9 |
| 简单结构，20 条偏移边界定位 | 12.8 → 13.2 | 12.7 → 13.9 |
| 简单结构，20 条带偏移完整恢复 | 261.8 → 258.5 | 264.6 → 258.9 |
| 简单结构，20 条全文回退完整恢复 | 641.5 → 621.0 | 654.1 → 663.0 |
| 分散节点，20 条偏移边界定位 | 20.1 → 21.7 | 20.5 → 21.7 |
| 分散节点，20 条带偏移完整恢复 | 286.5 → 287.8 | 288.1 → 286.1 |
| 分散节点，20 条全文回退完整恢复 | 968.1 → 874.9 | 923.2 → 913.9 |

隐藏场景的可见目标查询两轮减少约 61–63%，无匹配查询减少约 54–55%。样式读取每次均由 30,003 次减少到 5 次；错误偏移由 407,787 修正为 7。100 段隐藏场景约 0.3 → 0.1ms，接近计时粒度，不据此宣称稳定的小数据收益。

普通长页面独立偏移定位增加约 0.4–1.6ms，完整带偏移批次没有稳定改善。简单结构的全文回退一轮变快、一轮略慢；分散节点两轮变快，但幅度差别较大，不宣称稳定的普通页面总体性能提升。100 段普通页面的全文查询约 0.1–0.7ms，批次耗时受到每项让出主线程的影响；全部样本保留。

复用现有父元素缓存减少了普通页面全文搜索的重复样式读取，但新增祖先检查有成本；不能据此声称所有高亮都更快。缓存命中时直接返回，避免创建无用的祖先列表，未单独量化这一小处调整的收益。未采样分配或峰值堆字节数。

## 实际扩展与检查

Chrome for Testing 153.0.8010.12、测试用 Firefox 153.0 Nightly（build ID `20260722112722`，geckodriver 0.37.1）各通过 15 项脚本验收。Firefox 来自 Playwright 的测试包并含补丁，不代表正式发行版。

- 真实导入 10,000 条记录，按网址取出 20 条并使用返回记录恢复，移除偏移后也恢复同批 20 条；重复、清除、相邻文本及完整原文检查通过。
- 长页面原生选区保存、外部插入、CSSOM/媒体条件变化及原重复文本定位检查通过。
- 隐藏重复文字、隐藏选择器锚点及失效旧偏移组合只绘制可见目标；实际选区保存偏移 7、前文 `before `、后文 ` after`。
- 可覆盖的 `visibility:hidden` 与 `display:contents` 后代仍能绘制。
- Chrome 扩展/测试页无页面异常；Firefox 扩展 URL 来源的非警告脚本错误为空。

新增选区验收发生在上述 10,000 条库验收之后，会保存一条测试摘录；没有将最后的 10,001 条库描述为始终不变的 10,000 条库。首次新增选区夹具误选清除高亮后留下的空文本节点，两浏览器断言失败；修正为实际目标 Text 后，完整脚本重新通过。临时浏览器配置已清理，不访问用户浏览器或摘录。

231 个测试、28 个文件通过 coverage；类型检查、Chrome/Edge/Firefox 构建、脚本语法和 diff 检查通过。构建仍提示一个超过 500kB 的代码块。完整原始样本、源码 SHA-256 与原生验收结果见 [performance-hidden-text-results.json](./performance-hidden-text-results.json)。
