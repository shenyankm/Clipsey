# 空白规范化的分配优化

2026-10-12；基线 `ec9fb59`。延续[Latin-1 文本边界映射验收](./performance-latin1-mapping.md)。主要摘录库规模仍为 10,000 条；本轮独立测量 100/10,000 段页面及每批 20 条无偏移高亮，分别计数。

## 改动与正确性

旧规则 `/\s+/g` 也替换每一个单独的普通空格，输出文字不变却有临时分配。当前用 `/\s{2,}|[^\S ]/g`，只替换至少两个连续空白，或一个普通空格以外的空白；单个普通空格保持原样。公开的规范化函数与全文查询共享该正则，其他匹配、大小写转换、原文边界、可见性检查及调度逻辑保留。

每个空白连续段长度至少为二时由第一分支完整折叠；长度为一时，普通空格原样保留，其他空白由第二分支转成普通空格。因此规范化的字符串内容与原规则相同，包括开头/末尾空白。全文仍保留规范化后首尾空格；只有原有公开 helper 执行 `trim`。没有增加接口或长期页面缓存。

新增一个穷举测试：当前 JS 运行时的 25 个空白代码单元，以及全部 625 种两字符组合，检查规范化结果、空白输入、原始 Range 内容及两端偏移；既有 256 个 Latin-1 字符、三字符连续空白、Unicode 展开、跨节点、隐藏节点与重叠匹配测试继续通过。两个调用位置复用的全局正则由 `String.replace` 使用，连续调用也包含在上述检查中。

## 分配对照

Headless Chrome 155、macOS、Node.js 22.23.2、独立临时配置。每项七次取中位数；DOM 准备及 GC 在采样前完成，仅采样一次尾部查询与原文边界断言。CDP HeapProfiler 间隔 16,384 字节，计入采样期间已被大小 GC 回收的对象；每个样本都核对分配位置之和等于总量。

四个独立进程按基线正序、当前正序、当前反序、基线反序执行。普通夹具每段五个文本节点；稀疏夹具仅在最后一段追加一个 Tab 文本节点，分配准备阶段使用序列化 HTML 重新构造页面。10,000 段尾部查询的采样 JS 分配量如下，MB 按 1,000,000 字节计算：

| 文本 | 正序：基线 → 当前 | 反序：基线 → 当前 |
| --- | --- | --- |
| Latin-1，普通空格 | 14.60 → 6.90 | 14.79 → 6.85 |
| 中文与英文混排，普通空格 | 25.31 → 16.03 | 25.11 → 15.64 |
| Unicode 空白、展开与 emoji | 24.85 → 20.64 | 24.93 → 20.32 |
| 仅末尾追加 Tab | 14.50 → 7.92 | 14.72 → 7.83 |

普通空格的 Latin-1 场景减少约 53–54%，中文混排约 37–38%，混合 Unicode 约 17–19%，稀疏空白约 45–47%。普通空格场景与稀疏场景的 `replace` 位置未记录到采样分配；混合 Unicode 该位置中位数从约 7.2–7.4MB 降至约 3.0MB。采样不能证明某个函数绝对零分配。

这是临时 JS 分配的估计，包含已回收对象，不是峰值堆、常驻堆、原生 DOM 内存或泄漏检测。100 段也观察到较小采样量，但不以接近采样粒度的数值作为硬阈值。

## 未采用预检查方案

另测一个候选：先用非全局正则检查是否有非普通空格或双空格；需要转换时执行旧替换，否则跳过替换。普通空格文本能减少分配，但混合 Unicode 与末尾稀疏空白仍走旧替换。后者还需要先检查到整页末尾。

同一四布局夹具下的一轮七次采样中位数，单位 MB：

| 文本 | 基线 | 预检查候选 | 当前直接替换 |
| --- | --- | --- | --- |
| Latin-1，普通空格 | 14.60 | 7.00 | 6.90 |
| 中文与英文混排，普通空格 | 25.31 | 15.83 | 16.03 |
| Unicode 空白、展开与 emoji | 24.85 | 24.12 | 20.64 |
| 仅末尾追加 Tab | 14.50 | 14.40 | 7.92 |

普通空格场景两种方案相近，当前直接替换在后两种场景减少更多分配，因此选择它。没有用分配进程中的耗时数值给候选排序；未宣称预检查方案在 CPU 上更慢。候选完整源码、样本与哈希保留在原始结果中。

## 独立耗时对照

最终四布局的正式耗时测量在上述分配采样之后，另起四个浏览器进程，执行基线正序、当前正序、当前反序、基线反序。全部计时串行，没有并行运行 Vitest、构建、原生浏览器验收或分配采样。夹具准备后等待两个动画帧，预热一次再采样七次；各次都核对目标 Text、UTF-16 偏移和完整原文。

| 文本 | 正序：基线 → 当前 | 反序：基线 → 当前 |

| Latin-1，普通空格 | 22.9 → 21.1 | 23.6 → 21.8 |
| 中文与英文混排，普通空格 | 30.2 → 30.9 | 31.8 → 30.7 |
| Unicode 空白、展开与 emoji | 32.8 → 30.9 | 31.1 → 31.6 |
| 仅末尾追加 Tab | 22.3 → 21.2 | 21.7 → 21.0 |

Latin-1 尾部定位两轮减少约 8%；中文与混合 Unicode 未显示稳定单次耗时收益，不能根据分配量推导速度提升。头部、中部、缺失查询及逐次样本均保留。
