# Performance acceptance summary

The latest recorded acceptance run covers commit `7699784`, using **10,000 clips as the main dataset and 100 clips as a smaller comparison**. See the [page-endpoint report](./performance-page-endpoints.md) for comparisons and limitations, and the [raw results](./performance-page-endpoints-results.json) for all samples. Performance work has stopped; these results do not establish that performance is optimal. The measured implementation is now on `main`.

Verified results from that stage:

- Deep pages with integer offsets capture only their first and last index keys. Index-key reads fell from 100 to 2 for a full 100-row page and from 20 to 2 for a full 20-row page. Partial final pages still retain a reusable last boundary.
- Across eight Chrome allocation comparisons with 10,000 clips and 100-row pages, median self-allocation at the cursor callback fell by about 31%–75%. Total sampled allocation and complete query time did not improve consistently. Slower samples and interleaved diagnostic repeats remain in the report.
- That acceptance stage passed 462 tests, application and fixture type checks, Chrome/Edge/Firefox builds, and 21 actual management-page checks each in Chrome and Firefox. The subsequent directory cleanup and English documentation update did not rerun those checks or change the implementation or tests.

Small datasets retain the original shallow-page path. Existing regression tests cover cache revision checks, field budgets, failure handling, and data freshness. Long-term memory use, peak memory/RSS, low-end devices, actual user access patterns, the Edge runtime, and remote CI were not measured. A reduction in allocation at one site does not establish an overall extension speedup.

## Reproduce the measurements

Install dependencies using the Node.js and pnpm versions specified in the [README](../README.md). Run the existing scripts with isolated synthetic data:

```sh
BASELINE_REF=08326ed node scripts/performance.mjs --page-endpoints --baseline
node scripts/performance.mjs --page-endpoints
node scripts/performance.mjs --page-endpoints --reverse
BASELINE_REF=08326ed node scripts/performance.mjs --page-endpoints --baseline --reverse
```

Add `--allocations` for Chrome allocation sampling. Firefox timing comparisons use `scripts/firefox-highlight-scheduling.mjs`. See the detailed report for browser paths, prerequisites, and the existing fixture commands.
