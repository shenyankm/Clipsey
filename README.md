# Clipsey

Clipsey 是一款简洁高效的浏览器扩展,专为网页内容收藏而设计。无论是研究资料、学习笔记还是灵感片段,都能随手保存、快速检索,并一键回到原文位置。

**✨ 核心优势**
- 🔒 **隐私优先**: 无需注册账号,所有数据保存在浏览器本地
- ⚡ **即时收藏**: 选中内容右键即存,零学习成本
- 🎯 **精准定位**: 自动记录原文位置,一键返回上下文

## 功能特性

### 📌 右键一键收藏
选中网页上任意文本,右键菜单点击 `保存当前选中内容`,即可保存:
- 📝 原文内容(支持富文本格式)
- 🏷️ 页面标题与网址
- 🖼️ HTML 样式片段
- 📍 精确的页面位置信息

**适用场景**: 阅读文章时标注重点、收集研究资料、保存产品描述、记录灵感片段

### 🗂️ 抽屉式收藏库
点击浏览器工具栏的 Clipsey 图标,即可打开收藏管理面板:
- 🔍 **智能搜索**: 快速定位关键词内容
- 📊 **分组展示**: 按网站或时间自动归类
- 🎨 **直观预览**: 保留原文格式与样式
- 🗑️ **批量管理**: 一键清理过期内容

**适用场景**: 整理学习笔记、查找历史收藏、管理知识库

### 🎯 一键返回原文
在收藏列表中点击 `打开` 按钮,Clipsey 会:
1. 在新标签页打开原网页
2. 自动滚动到收藏时的精确位置
3. 高亮显示原文内容(如页面未改动)

**适用场景**: 查看完整上下文、核对引用来源、继续深度阅读

### 🔐 数据安全与隐私
- ✅ 所有数据存储在浏览器本地,不上传任何服务器
- ✅ 离线工作,无需网络连接
- ✅ 不收集任何用户信息
- ✅ HTML 内容自动净化,防止恶意脚本

## 快速开始

### 安装扩展

**方法一: Chrome 扩展商店(推荐)**
> 📢 已上架 Chrome Web Store!

**方法二: 手动安装(开发者模式)**

1. 下载 [最新版本](https://github.com/your-repo/releases) 并解压
2. 在 Chrome 地址栏输入 `chrome://extensions`
3. 右上角开启「开发者模式」
4. 点击「加载已解压的扩展程序」
5. 选择解压后的文件夹
6. Clipsey 图标将出现在浏览器工具栏

### 基本使用

**步骤 1: 收藏内容**
- 在网页上选中想要保存的富文本
- 右键点击选择 `保存当前选中内容`
- 看到选中内容高亮即表示收藏成功

**步骤 2: 查看收藏**
- 点击工具栏的 Clipsey 图标
- 浏览所有收藏的内容
- 使用搜索框快速查找

**步骤 3: 返回原文**
- 在收藏列表中找到目标内容
- 点击 `Open` 按钮
- 自动打开原网页并定位到原文位置

## 常见问题

**Q: Clipsey 需要联网使用吗?**  
A: 不需要。所有功能完全离线工作,收藏和查看都不依赖网络。

**Q: 我的数据存储在哪里?**  
A: 所有收藏内容保存在浏览器本地存储中,不会上传到任何服务器。

**Q: 可以在多台电脑间同步吗?**  
A: 目前不支持自动同步功能。

**Q: 为什么有些网页无法返回原文位置?**  
A: 如果网页内容已被修改或删除,可能无法精确定位。建议收藏时选择相对稳定的内容。

**Q: 收藏数量有限制吗?**  
A: 受限于浏览器本地存储容量,建议定期清理不需要的收藏以保持最佳性能。
